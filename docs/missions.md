# Как добавить миссию

Создайте отдельный JSON-файл в `src/missions/presets/`.
Каталог подхватывает файлы автоматически; менять общий список не нужно.

## Одна волна

Пример `quiet-orbit.json`:

```json
{
  "id": "quiet-orbit",
  "title": "Тихая орбита",
  "description": "Очистите одну волну из трёх медленных астероидов вместе с их осколками.",
  "seed": 73,
  "asteroidCount": 3,
  "asteroidSpeed": 0.6,
  "mode": "clear"
}
```

В clear нет новых волн. После последнего осколка игра показывает победу.
Прогресс учитывает попадания: большой астероид и его осколки требуют
семи попаданий, поэтому для трёх начальных целей нужно 21.

## Выживание в потоке

```json
{
  "id": "fast-stream",
  "title": "Быстрый поток",
  "description": "Продержитесь 45 секунд среди астероидов, входящих справа.",
  "seed": 2026,
  "asteroidCount": 8,
  "asteroidSpeed": 1.6,
  "mode": "survival",
  "durationSeconds": 45,
  "spawnIntervalSeconds": 1.25
}
```

Начальные астероиды движутся справа налево. Далее новые появляются по времени,
а вышедшие за левую границу удаляются. Пустое поле не завершает миссию.
Победа наступает по таймеру, если остаётся хотя бы одна жизнь.
Пауза останавливает таймер; рестарт возвращает исходный seed и параметры.
На заполненном поле очередное появление может быть пропущено.

## Контракт

- id уникален: строчные латинские буквы, цифры и разделяющие слова дефисы.
  Назовите файл по id.
- title и description — непустые строки.
- seed — целое число в безопасном диапазоне JavaScript.
- asteroidCount — целое от 1 до 30.
- asteroidSpeed — конечное положительное число; 1 означает базовую скорость.
- mode — clear, survival, dream-rally или waves. Если поле отсутствует, используются
  прежние бесконечные волны; существующие JSON продолжат работать.
- durationSeconds — от 1 до 600, по умолчанию 60; используется в survival.
- spawnIntervalSeconds — от 0,25 до 10, по умолчанию 1,25; используется в survival.
- requiredHits — необязательное число попаданий от 0 до 1000; если цель не выполнена к концу survival, миссия проиграна.
- theme — необязательное оформление: classic (по умолчанию) или pink.
  Меняет цвета интерфейса и игрового поля, не влияет на симуляцию.

«Барби: курс на Дримхаус» использует режим dream-rally. За 90 секунд нужно
собрать три сердца, пережить 20 секунд шторма и войти в портал справа.
Сердце даёт один заряд щита (максимум два), тройной залп на шесть секунд
и мгновенную перезарядку рывка. Shift даёт защитный рывок на 0,25 секунды,
перезарядка — три секунды. Сердца притягиваются с расстояния 115 пикселей.
Во время шторма поток становится быстрее и плотнее. Лазеры предупреждают
о выстреле за 1,4 секунды. Портал появляется только после шторма.
Истечение общего времени означает поражение. Для dream-rally длительность
должна быть не меньше 45 секунд.
Розовая тема включается при выборе миссии и сохраняется при повторе.
Открыть её сразу можно по адресу `/?mission=barbie-dream-orbit`.
Параметр `mission` принимает любой id из каталога; неизвестный id открывает
обычную стартовую миссию.

Встроенный «Первый вылет» — clear с тремя медленными астероидами.
«Плотный пояс» — survival на 60 секунд с восемью начальными астероидами
и пополнением каждые 1,25 секунды.

## Проверка

```sh
npm test
npm run build
npm run test:e2e
```

Тесты читают все JSON-файлы миссий и проверяют их контракт.
В браузере убедитесь, что цель понятна до старта, прогресс соответствует
игре, а победа, поражение и рестарт работают для выбранного режима.

Для PR достаточно нового файла и описания проверенного сценария.
Изменения общего кода нужны, только если добавляется новая механика или параметр.

## Миссия с НЛО

`uninvited-guest.json` («Незваный гость») включает `ufoEnabled: true` в режиме
`survival`. По умолчанию флаг выключен; в других режимах включать его нельзя.
Первое НЛО входит слева через 2 секунды, движется со скоростью 110 пикселей/с
и стреляет в текущую позицию игрока каждые 1,5 секунды. Скорость снаряда —
210 пикселей/с. Одно попадание уничтожает НЛО и приносит 200 очков.
Следующее появляется через 5 секунд после уничтожения или ухода за экран.
Вражеские снаряды не переносятся через края. Попадания и столкновения с НЛО
учитывают общие жизни и двухсекундную неуязвимость корабля.
